# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| main   | Да        |

## Сообщение об уязвимости

Если вы обнаружили уязвимость, пожалуйста:

1. Не публикуйте её публично
2. Создайте issue с пометкой `[SECURITY]`
3. Опишите проблему и шаги для воспроизведения

Мы рассмотрим сообщение в течение 72 часов.

## Секреты

- Никогда не коммитьте секреты в репозиторий
- Используйте `.env` для локальной конфигурации
- Все секреты хранятся в GitHub Secrets на уровне организации
