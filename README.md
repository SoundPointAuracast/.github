# .github — «Точка звука»

Служебный репозиторий организации: визитка, шаблоны issue и PR.

## Содержимое

```
profile/README.md              — визитка организации
ISSUE_TEMPLATE/                — шаблоны issue
  bug_report.md                — сообщение о баге
  feature_request.md           — запрос новой функции
  measurement_report.md        — отчёт об измерении (НИОКР)
PULL_REQUEST_TEMPLATE.md       — шаблон pull request
CODE_OF_CONDUCT.md             — кодекс поведения
SECURITY.md                    — политика безопасности
```

## Репозитории организации

- [auracast](https://github.com/SoundPointAuracast/auracast) — монорепозиторий, программная часть
- [firmware](https://github.com/SoundPointAuracast/firmware) — аппаратная часть, отдельный тулчейн
- docs — визитка, шаблоны, организационная документация (этот репозиторий)
