# Точка звука

Локальная Auracast-система персональной передачи речи и цифрового
сопровождения для образовательных и общественных пространств.

## О проекте

«Точка звука» — аппаратно-программная ассистивная система для людей
с нарушением слуха. Один источник речи используется в двух параллельных
трактах:

- **AUDIO:** речь → Auracast Broadcast → совместимые наушники, слуховые
  аппараты, кохлеарные импланты
- **DATA:** речь → локальное распознавание → субтитры, «Не расслышал»,
  заметки, закладки

Для устройств с T/MT предусмотрен путь через Bridge-T.
