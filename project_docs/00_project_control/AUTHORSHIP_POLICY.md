# AUTHORSHIP_POLICY

Дата: 2026-09-26. Статус: ACCEPTED (обязательный документ проекта).

## Основное

| Поле | Значение |
|---|---|
| PROJECT | «Инклюзивный маршрут+ / Точка звука» |
| AUTHOR | **Никитин Даниил Константинович** |
| AUTHOR_COUNT | **1** |

Автор является единственным автором текущей концепции проекта.

## Допустимые формулировки

- «автор проекта», «разработчик», «автором предложено»;
- «в проекте предлагается»;
- «разработано автором», «авторская концепция»;
- «проект», «команда проекта» — **не использовать** там, где речь идёт
  об авторстве концепции.

## Недопустимые формулировки для текущего проекта

- «наша команда», «члены команды», «команда проекта разработала»;
- «мы разработали» (если подразумеваются несколько авторов);
- «соавторы»;
- «авторы» (во множественном числе) применительно к текущей концепции.

## Разграничение ролей

| Роль | Соавтор? |
|---|---|
| AUTHOR | — (это и есть автор) |
| CONSULTANT | **НЕТ** |
| SUPERVISOR (научный руководитель) | **НЕТ** |
| TEST PARTICIPANT (испытатель) | **НЕТ** |
| EMPLOYER (работодатель) | **НЕТ** |
| CONTRACTOR (подрядчик разработки) | **НЕТ** |
| HISTORICAL CONTRIBUTOR | **НЕТ** для текущей концепции |

Участие в испытаниях, консультирование, предоставление площадки или
финансирование **не создаёт авторства**.

## Исторические материалы

В `01_sources/` (S001–S011) встречаются слова «команда», «соавторы» и т.п.
Это **исторические документы**; их содержание не изменяется. При
цитировании следует явно указывать: «цитата из исторического материала
Sxxx». Историческое авторство не переносится автоматически на текущую
концепцию.
