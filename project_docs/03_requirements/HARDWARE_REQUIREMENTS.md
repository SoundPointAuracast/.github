# HARDWARE_REQUIREMENTS

Статус: DRAFT. PCB не проектируется на текущем этапе.

## Узлы

| Узел | Назначение |
|---|---|
| Auracast source | Формирование LE Audio Broadcast из чистого аудио |
| Auracast receiver | Приём Auracast (для Bridge-T и тестов) |
| Bridge-T | Auracast Sink → LC3 decode → PCM → DAC → усилитель → индукционная катушка → T/MT |
| Existing inductor | Уже существующая разработка беспроводного индуктора |
| Devkits | Отладочные платы для исследований |
| BOM | Перечень компонентов и стоимость |

## Предварительная архитектура Bridge-T (HYPOTHESIS)

Auracast Broadcast Sink
→ LC3 decode
→ PCM
→ DAC / audio codec
→ усилитель
→ индукционная катушка
→ T / MT режим
→ слуховой аппарат / кохлеарный имплант.

**Не считать эту архитектуру уникальной** до анализа аналогов
и патентов (`09_novelty_rid/`, `02_research/10_patents_prior_art/`).

## Требования (черновые)

- HW-01 (TARGET): питание узлов и время автономной работы — определить.
- HW-02 (TARGET): уровень сигнала индукционной катушки в пределах
  безопасных и совместимых норм.
- HW-03 (ENGINEERING ASSUMPTION): Bridge-T совместим с T/MT слуховыми
  аппаратами и КИ — требует проверки.
- HW-04 (ASSUMPTION): возможно использование готовых devkit-модулей
  вместо собственной платы на первом этапе.

## Открыто

- Выбор чипсетов / модулей (требует MAX-режима).
- Нормы индукции, ЭМС, сертификация.
- Совместимость с реальными моделями слуховых аппаратов и КИ.
