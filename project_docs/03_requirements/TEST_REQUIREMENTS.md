# TEST_REQUIREMENTS

Статус: DRAFT. Определяет, какие характеристики нужно измерить,
прежде чем называть их MEASURED RESULT.

## Принцип замера

| Параметр | Как измерять | Где |
|---|---|---|
| Сквозная задержка | audio → Auracast → приём, метка времени | `07_experiments/latency/` |
| Качество звука | MOS / разборчивость / субъективная оценка | `07_experiments/audio_quality/` |
| Покрытие | уровень сигнала / потеря пакетов по зонам | `07_experiments/rf_coverage/` |
| Совместимость | список реальных устройств | `07_experiments/compatibility/` |
| Точность ASR | WER/CER на чистом фиде и на микрофоне телефона | `07_experiments/asr_accuracy/` |
| Индукция | уровень поля, совместимость с T/MT | `07_experiments/induction/` |
| Пользователи | сценарии из USER_REQUIREMENTS | `07_experiments/user_testing/` |

## Требования к протоколам

- TR-01: у каждого измерения — протокол, условия, оборудование, дата.
- TR-02: указывать погрешность и методику.
- TR-03: результат хранить в соответствующем каталоге experiments.
- TR-04: в отчётах помечать MEASURED RESULT явно.

## Запрещено

- Переносить числа из сторонних источников в свои измерения
  без ссылки и воспроизведения.
- Округлять/выдавать целевые значения за измеренные.
