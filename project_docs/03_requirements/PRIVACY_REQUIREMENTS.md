# PRIVACY_REQUIREMENTS

GATE 4B. Дата: 2026-09-26. Принцип: **privacy-by-default**.

## Категории данных

| Категория | Что | Хранение в MVP | Примечание |
|---|---|---|---|
| Temporary processing | аудио в момент распознавания | в памяти процесса, не на диск | удаляется сразу после ASR |
| Transcript storage | сегменты текста | в памяти сессии (backend) | исчезают при остановке; demo — локальный fixture |
| User notes | заметки пользователя | LocalStorage (браузер) | на устройстве пользователя |
| Bookmarks | закладки | LocalStorage | на устройстве пользователя |
| Audio recording | запись лекции | **НЕ производится** | отключено по умолчанию |

## Требования

- P-01: сырое аудио **не сохраняется permanently**.
- P-02: transcript хранится только на время сессии (или локально в demo).
- P-03: заметки и закладки — **локально**, не отправляются на сервер.
- P-04: запись аудио отсутствует в MVP; её добавление требует отдельного
  решения и политики.
- P-05: согласие (consent) — для реального пилота обязательна процедура
  информирования лектора/студентов (вне MVP).
- P-06: сервер не должен логировать содержимое аудио.
- P-07: экспорт данных — только явным действием пользователя.

## Consent (для будущего пилота)

- Информирование о трансляции речи в текст.
- Возможность отказа / приостановки.
- Разграничение доступа к сессии.

## Открытые вопросы

- Срок ретенции транскрипта в реальной эксплуатации.
- Правовой режим (персональные данные, аудитория).
- Локальный on-device ASR как способ снизить риски.
