# AUDIO_REQUIREMENTS

Статус: DRAFT. Все числовые значения — TARGET, не MEASURED RESULT.

## Тракт

Микрофон преподавателя / микшер / PA → цифровой аудиосигнал →
обработка → LC3 → Bluetooth LE Audio Broadcast (Auracast) →
совместимое устройство пользователя.

## Требования (черновые, категории явные)

- AU-01 (TARGET): разборчивость речи выше, чем при приёме
  акустического сигнала микрофоном смартфона в зале.
- AU-02 (TARGET): низкая сквозная задержка. **Конкретное число
  (30/50/300 мс) не фиксируется до измерений.**
- AU-03 (TARGET): стабильность потока в пределах помещения.
- AU-04 (ENGINEERING ASSUMPTION): источник сигнала — «чистый фид»
  (микрофон преподавателя / выход микшера), а не акустика зала.
- AU-05 (HYPOTHESIS): один источник пригоден одновременно для
  аудиопотока и для ASR.

## Нельзя утверждать без проверки

- гарантированную задержку;
- универсальную дальность (например, «100 м»);
- бесконечное число слушателей;
- seamless roaming;
- совместимость со всеми устройствами.

## Открыто

- Формат входного сигнала (аналог/цифра, уровни, разъёмы).
- Требования к обработке (AEC, NS, AGC) — нужны ли и в каком месте.
- Как измерять разборчивость (методика, метрики).
