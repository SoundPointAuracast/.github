# ACCESSIBILITY_REQUIREMENTS

Статус: DRAFT. Назначение — обеспечить инклюзивность как основной принцип.

## Целевые группы

- Первичная: слабослышащие, пользователи слуховых аппаратов,
  пользователи кохлеарных имплантов.
- Вторичная: студенты на дальних рядах, участники конференций,
  иностранные студенты, пользователи в шуме / реверберации.

## Принцип

«Для большинства пользователей это удобство.
Для человека с нарушением слуха — доступ к информации».

## Требования интерфейса

- AR-01 (TARGET): крупный текст, масштабирование без потери вёрстки.
- AR-02 (TARGET): высокий контраст / тёмная тема.
- AR-03 (TARGET): соответствие принципам доступности мобильных ОС.
- AR-04 (TARGET): отсутствие зависимости от звука для доступа к смыслу
  (текст как полноценный канал).
- AR-05 (TARGET): низкая когнитивная нагрузка при входе в сессию.
- AR-06 (TARGET): настраиваемый темп/размер живого транскрипта.
- AR-07 (HYPOTHESIS): персональный профиль доступности.

## Нельзя

- Обещать совместимость со всеми слуховыми аппаратами / КИ.
- Обещать, что текст полностью заменяет слух — это вспомогательный слой.

## Открыто

- Стандарты доступности, которым должен соответствовать продукт
  (WCAG-уровень, платформенные гайдлайны) — требуют исследования.
