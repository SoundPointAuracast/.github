# SOURCE OF TRUTH

## Актуальные технические требования

Актуальными считаются требования и решения, зафиксированные в:

- `03_requirements/` — требования (пользовательские, доступность, аудио, приложение, железо, тесты)
- `04_architecture/` — архитектурные описания
- `PROJECT_STATE.md` — текущее состояние проекта

Эти документы имеют приоритет при любых противоречиях.

## Старые презентации, заявки, выступления

Материалы в:

- `01_sources/legacy_presentations/`
- `01_sources/applications/`
- `01_sources/speeches/`
- `99_archive/`

**НЕ являются техническим source of truth.**

Они имеют статус:

- LEGACY
- HISTORICAL
- CONCEPT SOURCE

## Правило повторного использования старых утверждений

Если старое утверждение используется в новой версии проекта,
его нужно заново проверить и, при необходимости:

1. присвоить статус `REVIEWED` или `VERIFIED` в `01_sources/source_register.csv`;
2. привязать к конкретному требованию или архитектурному решению;
3. отделить FACT от ENGINEERING ASSUMPTION / HYPOTHESIS / TARGET.

## Таксономия утверждений

Каждое техническое утверждение в проекте должно быть отнесено к одной из категорий:

| Категория | Значение |
|---|---|
| FACT | Установленный, проверяемый факт |
| SOURCE | Утверждение со ссылкой на внешний источник |
| ENGINEERING ASSUMPTION | Инженерное допущение, ещё не проверенное |
| HYPOTHESIS | Научная / техническая гипотеза для проверки |
| TARGET | Планируемый параметр (не измеренный!) |
| MEASURED RESULT | Измеренная характеристика, полученная в эксперименте |

## Критическое правило

Планируемый параметр (TARGET) **нельзя** выдавать за измеренную
характеристику (MEASURED RESULT). Любое число должно иметь явную
категорию и, по возможности, ссылку на источник или протокол измерения.

## Не считается установленным без отдельной проверки

- Bluetooth 5.2 = Auracast
- любые Bluetooth-наушники поддерживают Auracast
- любое LE Audio устройство поддерживает Auracast
- бесконечное число слушателей
- универсальная дальность 100 м
- гарантированная задержка 30/50/300 мс
- seamless roaming
- совместимость со всеми слуховыми аппаратами
- совместимость со всеми кохлеарными имплантами

См. `00_project_control/DECISIONS.md` и `12_reports/CONCEPT_AUDIT.md`.
