# SLIDE_ASSISTIVE_AUDIO_EVOLUTION

Слайд: **«От радиокласса к цифровой доступной аудитории»**.
Статус: контент для будущей презентации (сам PPTX не редактируется).

## Компоновка (3 колонки)

### Слева — FM / Roger (проверенная классика)

```
Преподаватель
     ↓
специальный передатчик
     ↓
специальный приёмник
     ↓
СА / КИ (T/MT, DAI)
```
Подпись: «Речь — в ухо, без расстояния и шума. Работает десятилетиями.»

### Центр — Auracast (открытый транспорт)

```
Преподаватель
     ↓
Broadcast Source
     ↓
совместимые персональные устройства
(наушники, СА, КИ — совместимые модели)
```
Подпись: «Открытый стандарт. Один источник — много слушателей.»

### Справа — Точка звука (исследуемый слой)

```
             Clean Feed
           ↙            ↘
       Auracast          ASR
          ↓               ↓
        Audio          Route+ App
                          ↓
              текст / «Не расслышал»
              / заметки / доступность
```
Подпись: «Тот же чистый источник — и звук, и синхронизированный текст.»

## Честный вывод (обязательная плашка)

> «Проект не заменяет доказавшие эффективность FM/Roger-системы, а
> исследует следующий этап: единую доступную цифровую аудиосреду с
> персональным звуком и синхронизированным текстовым сопровождением».

## Ограничения слайда

- Не утверждать, что Auracast «лучше» Roger: у них разные свойства
  (открытость/массовость против зрелости/SNR/сети микрофонов).
- Не утверждать, что СОНЕТ устарел: он продаётся и решает свою задачу.
- Не заявлять новизну clean-feed: подтверждено у Roger NeckLoop (2021).
- Не приводить неподтверждённые цифры (100 м, «без задержек»).
