# EXPERIMENT_READINESS_GATE6

GATE 6A. Дата: 2026-09-26. Готовность E01, E03, E04, E07.

Легенда: READY = протокол полный; READY-ON-HW = зависит от закупки
оборудования; PROTOCOL = протокол есть, детали CSV уточняются.

---

## E01 — Audio latency

| Поле | Значение |
|---|---|
| Оборудование | 2× nRF5340 Audio DK (source+sink); осциллограф/звуковая карта (≥1 мс); кабели |
| Схема стенда | источник (генератор/ПК) → line-in TX → эфир → RX → line-out → измерение |
| Точка подачи сигнала | электрический вход TX (короткий burst/чирп) |
| Точка измерения | аналоговый выход RX |
| Метрика | e2e latency (mean/median/p95/max), jitter |
| Число повторов | ≥100 на конфигурацию; конфигурации: 16_2_1, 16_2_2, 24_2_1, 24_2_2; PD 20/30/40 мс |
| Что сохраняется | `e01_latency.csv` (run_id, config, qos, pd_ms, latency_ms, condition) |
| Acceptance | TARGET ≤60 мс; ACCEPTABLE ≤100 мс; REJECT >150 мс |
| Статус | **READY-ON-HW** |

## E03 — Packet stability

| Поле | Значение |
|---|---|
| Оборудование | тот же стенд; длительная запись (≥1 ч) |
| Схема | источник → TX → RX; лог качества (если доступно) + аудио |
| Точка подачи | непрерывный аудиопоток |
| Точка измерения | выход RX + счётчики (если доступны) |
| Метрика | разрывы, глитчи, потери/переповторы, длительность без сбоев |
| Повторы | ≥3 прогона по ≥1 ч; условия: тихо / движение людей / Wi-Fi нагрузка |
| CSV | `e03_stability.csv` (run_id, duration_s, dropouts, glitches, condition) |
| Acceptance | нет разрывов в сценарии лекции |
| Статус | **READY-ON-HW** |

## E04 — LC3 configuration comparison

| Поле | Значение |
|---|---|
| Оборудование | стенд E01 + панель слушателей (≥8) + наушники |
| Схема | один и тот же речевой материал в разных конфигурациях |
| Точка подачи | line-in TX |
| Точка измерения | выход RX (запись) + субъективные оценки |
| Метрика | субъективная разборчивость (шкалы), technical latency, airtime, совместимость |
| Повторы | ≥3 фрагмента × ≥8 слушателей, слепое сравнение |
| CSV | `e04_lc3.csv` (config, qos, listener_id, score, latency_ms) |
| Acceptance | выбранная база проходит и технически, и субъективно |
| Статус | **READY-ON-HW** |

## E07 — Bridge-T audio transfer

| Поле | Значение |
|---|---|
| Оборудование | Auracast sink с 3.5 мм (AuraClip / nRF5340 DK) → neckloop (Williams NKL 001 / HearCoil) → СА с T/MT; опционально старый индуктор |
| Схема | source → эфир → sink → усилитель (если нужно) → катушка → СА |
| Точка подачи | эфир Auracast |
| Точка измерения | слышимость/разборчивость в T-режиме; поле (при наличии тесламетра) |
| Метрика | уровень/разборчивость (субъективно), гул, влияние расстояния 1–10 см |
| Повторы | ≥10 прослушиваний на конфигурацию; ≥2 модели СА (если доступны) |
| CSV | `e07_bridge.csv` (device, coil, distance_cm, level_1_5, hum, notes) |
| Acceptance | стабильный разборчивый сигнал без гула сверх ожидаемого |
| Статус | **READY-ON-HW** (нужен СА с T/MT и neckloop) |
