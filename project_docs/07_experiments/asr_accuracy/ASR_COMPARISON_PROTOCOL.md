# ASR_COMPARISON_PROTOCOL — E05 (финальный протокол)

GATE 6A. Дата: 2026-09-26. Статус: READY (протокол; эксперимент не проведён).

## Цель

Проверить, даёт ли **clean-feed преподавателя** измеримое преимущество
распознавания речи по сравнению с **микрофоном смартфона** в учебной
аудитории. Результат не предрешён: до измерения вывод не делается.

## Гипотеза

H1: WER(FEED) < WER(PHONE) в типовой лекционной аудитории; разрыв растёт
с дистанцией, шумом и реверберацией.
Статус: HYPOTHESIS (см. `CLEAN_FEED_ASR_RESEARCH.md`).

## Условия (5)

| ID | Условие | Как создаётся |
|---|---|---|
| A | тихо / близко | пустая аудитория, телефон ~1 м |
| B | дальний ряд | телефон на последнем ряду (10–20 м) |
| C | фоновый шум | записанный шум зала / разговоры на заданном LAeq |
| D | реверберация | аудитория с RT60 выше (или RIR-свёртка) |
| E | шум + расстояние | комбинация B и C |

Каждое условие характеризуется измерениями: RT30/T20, C50, LAeq, SNR на
позиции телефона.

## Каналы записи (одновременно, тот же материал)

- **CH1 — clean teacher feed:** электрический выход микрофона/микшера
  преподавателя (PCM), без акустики зала.
- **CH2 — smartphone microphone:** ≥2 модели телефонов на позиции студента
  (зафиксированные настройки; документировать AGC/шумоподавление).

Речь: один и тот же материал, один лектор, повторяемый текст (скрипт) +
спонтанный фрагмент; ≥10 повторов на условие.

## Зависимые переменные (метрики)

| Метрика | Определение |
|---|---|
| **WER** | word error rate против reference (нормализация одинакова для всех условий) |
| **CER** | character error rate |
| **caption latency** | время от произнесения до появления partial/final на клиенте |
| **partial stability** | доля partial-гипотез, изменённых до final; число правок на сегмент |
| **finalization latency** | задержка финализации сегмента (Nguyen-подобная метрика) |

Дополнительно: timestamp precision (100/200/500 мс), hallucination rate.

## Оборудование

- 2–4 смартфона (разные классы), авиарежим, фиксированная ориентация.
- Чистый фид: запись электрического выхода (интерфейс/рекордер).
- Шумомер/измерительный микрофон; генератор шума/колонка.
- RIR-измерения зала (для факторного симуляционного рукава).

## Метод

1. Одновременная запись CH1 и CH2 (без повторных прогонов).
2. Reference: ручная верификация транскрипта CH1 + выравнивание
   (2 аннотатора на стратифицированной подвыборке, IAA).
3. Транскрибировать все условия **одним движком** с одинаковыми
   параметрами; повторить ≥2 движками (модель-агностичность).
4. Симуляционный рукав: CH1 × RIR × SNR (+20/+15/+10/+5/0 дБ) для
   разложения механизмов.
5. Статистика: mixed-effects regression; paired-сравнение FEED vs PHONE;
   bootstrap 95% CI; предрегистрация основной пары (FEED vs PHONE, условие E).

## Критерии

- Гипотеза поддерживается, если FEED даёт статистически значимое снижение
  WER и/или caption latency в условиях B–E.
- Если разрыв мал (< 1–2 WER пункта) — гипотеза не подтверждается,
  архитектура текстового слоя пересматривается.
- Никаких выводов до измерения.

## Что сохраняется

- CSV по условиям: condition, channel, phone_model, wer, cer,
  caption_latency_ms, partial_edits, finalization_ms, timestamp_precision.
- Сырые записи — только на время эксперимента (privacy; не архивировать
  без согласия).

## Ограничения

- FEED не содержит вопросов аудитории (анализировать сегменты лектора
  отдельно).
- DSP телефонов различается; фиксировать/документировать.
- Domain/accent эффекты.
