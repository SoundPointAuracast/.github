# CLAIM_CANDIDATES

Статус: ПУСТО / PRELIMINARY.

Формулировки-кандидаты **не являются** патентными притязаниями.
Это лишь рабочие гипотезы для последующей проверки.

## Возможные направления (черно)

- C-1: Способ, при котором единый чистый речевой сигнал подаётся
  одновременно в тракт LC3/Auracast и в тракт ASR с временной
  привязкой текста к аудио.
- C-2: Переходное устройство Auracast → индукционная катушка с
  управлением режимом T/MT.
- C-3: Механизм «Не расслышал» с возвратом к сегменту по timestamp.
- C-4: Отображение confidence в ассистивном транскрипте.

## Требуется до формулирования

- Prior art search.
- Анализ отличительных признаков.
- Оценка неочевидности.
- Юридическая консультация.
