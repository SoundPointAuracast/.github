# DISTRIBUTED_NODES

Статус: RESEARCH / FUTURE. Не реализуется в MVP.

## Идея

Для больших помещений:

```
central source
   -> local network
   -> several Auracast nodes
```

## Открытые вопросы

- Синхронизация нескольких передатчиков во времени.
- Roaming между узлами (seamless roaming — не утверждать заранее).
- Единый ли BIG/BIS на узлах или независимые.
- Задержка при переключении узлов.
- Авторизация и защита потока.

## Категория

Все свойства — HYPOTHESIS. Требуется MAX-режим и спецификации.
