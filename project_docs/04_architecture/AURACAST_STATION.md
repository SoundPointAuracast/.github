# AURACAST_STATION

Статус: DRAFT / HYPOTHESIS. Требует MAX-режима и ссылок на спецификации.

## Назначение

Формирование персонального аудиопотока из чистого сигнала
преподавателя и его широковещательная передача.

## Предполагаемый тракт

```
mic/mixer -> processing -> LC3 encode -> BIS/BIG -> Auracast broadcast
```

## Что нужно проверить (не утверждать заранее)

- Bluetooth 5.2 ≠ Auracast (проверить точные требования версии ядра).
- Не любое LE Audio устройство = Auracast.
- Число слушателей не бесконечно.
- Дальность не универсальна (не «100 м по умолчанию»).
- Задержка не фиксирована (не «30/50/300 мс по умолчанию»).
- Терминология: BAP, PBP, BASS, BIS, BIG — сверить со спецификациями.

## Категории

Все перечисленные характеристики — TARGET / HYPOTHESIS до проверки.
