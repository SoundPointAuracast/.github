Аудит численных и качественных утверждений о задержке. Дата: 2026-09-26, GATE 1.

## КРИТИЧЕСКОЕ ПРАВИЛО

Если нет **реального протокола измерения**, значение **не является
MEASURED RESULT**. В исходниках проекта протоколов измерения задержки
не обнаружено ни для одного числа.

## Поиск

Просканированы все извлечённые тексты. Числовые значения задержки:
обнаружено **ровно одно** — «≤300 мс» (S006). Значения «30 мс» и «50 мс»
в исходниках **отсутствуют** (вопреки предварительному ожиданию).

## Разбор L-001 (единственное число)

- **Источник:** S006 (заявка ФСИ), слайд 14, риск «Недостижение требуемой
  задержки», мера: «Закладываем реалистичный показатель ≤300 мс, проводим
  поэтапные испытания».
- **Категория:** TARGET (плановый KPI), **не измерение**.
- **Что измеряется:** в документе не уточняется (сквозная «микрофон → ухо»?
  канал Auracast? обработка?). Это открытый вопрос.
- **Вывод:** 300 мс — план, а не результат. Нельзя переносить как
  гарантированную характеристику на защите.

## Что отсутствует

- Числа 30 мс / 50 мс — не найдены (возможно, ожидались из внешних
  материалов, но в проекте их нет).
- Разделение задержки по участкам: кодирование LC3, broadcast, декодирование,
  обработка, индукция.
- Протоколы измерений.
