# LEGACY_ECONOMICS

Извлечение экономических утверждений из старых материалов.
Дата: 2026-09-26, GATE 1. Цифры **не переносятся автоматически**.

## Классификация

- `SOURCE-BASED` — есть внешний источник/бенчмарк.
- `ESTIMATE` — оценка авторов.
- `UNSUPPORTED` — без обоснования.
- `OUTDATED` — устарело (старый периметр проекта).
- `REQUIRES_NEW_CALCULATION` — нужен новый расчёт.

## Замечания

- Ни в одном источнике нет полного расчёта BOM/Unit-экономики.
- Все проценты эффектов (20–40%, 30–60%, +20%) — без методик.
- Смешение валют (₽ и USD) и отсутствие дат расчёта.
- Данные о ценах устройств сопоставимы с ИИ-заметкой S008 (устройства/цены).

## Что делать на GATE 5

1. Полностью пересчитать экономику под текущую концепцию (образование,
   Auracast + Bridge-T + Route+ App + ASR).
2. Источники цен — только с датами и ссылками (`10_economics/sources/`).
3. Разделять CAPEX/OPEX, прототип/серия, аренду/продажу.
4. Не переносить цифры из S003/S004.
